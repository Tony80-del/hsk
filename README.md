# HSK 课程体系 · HSK Course System

面向越南学员的 HSK 中文课程内容系统（HSK1 已导入，HSK2 / HSK3 结构就位待导入）。

## 在线地址

**https://tony80-del.github.io/hsk/**

手机、平板、电脑都能直接打开，不需要安装任何东西。

## 里面有什么

单文件、零依赖的网页应用（不引 CDN、不联网、可离线打开）。

| 层级 | 内容 |
|---|---|
| 第 1 层 | HSK1 / HSK2 / HSK3 三个级别 |
| 第 2 层 | HSK1 的 42 课平铺连号，顶部目录可按 6 节筛选 |
| 第 3 层 | 点某一课 → 学员课本 / 教师教案 两个页签，各自分块显示 |

- **学员课本** 7 块：生词 / 语法 / 例句 / 课文 / 练习 / 注意 / 课后任务
- **教师教案** 6 块：本课目标 / 语法点 / 课堂操练 / 易错点 / 课后任务 / 六步 SOP 对应表
- 「打印本课」会把两个页签的所有块展开成一份完整内容

## 术语

- **课** = 单个课程单元，HSK1 共 42 课
- **节** = 分组，HSK1 共 6 节（第一节 12 课 / 第二节 9 课 / 第三节 6 课 / 第四节 7 课 / 第五节 6 课 / 第六节 2 课）
- **主板块** = HSK1 / HSK2 / HSK3

## 本仓库说明

本仓库只存放**发布产物**（构建出来的 `index.html`），不存放生成脚本和源数据。
内容由本地生成脚本产出后发布到这里。
